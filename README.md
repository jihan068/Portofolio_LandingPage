# Portofolio Jihan Salma Salsabila

Website portofolio pribadi yang menampilkan profil, keahlian, proyek, dan informasi kontak Jihan Salma Salsabila, mahasiswa Manajemen Informatika yang berfokus pada Front-End Development.

## Fitur

- Tampilan responsif untuk desktop dan perangkat mobile.
- Navigasi ke bagian Home, About, Skill, Projects, dan Contact.
- Efek teks animasi pada bagian pembuka.
- Navigasi aktif yang mengikuti posisi scroll.
- Kartu proyek dengan tautan menuju desain Figma dan repositori GitHub.
- Formulir kontak yang mengirim pesan melalui [FormSubmit](https://formsubmit.co/).

## Teknologi

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3
- Bootstrap Icons
- Google Fonts

## Menjalankan secara lokal

Tidak diperlukan proses build atau instalasi dependensi. Clone repositori, lalu buka `index.html` di browser.

```bash
git clone https://github.com/USERNAME/NAMA-REPOSITORY.git
cd NAMA-REPOSITORY
```

Untuk pengalaman pengembangan yang lebih nyaman, buka folder proyek dengan VS Code dan jalankan `index.html` menggunakan ekstensi Live Server.

## Struktur proyek

```text
.
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── jihan.jpeg
```

## Deploy ke GitHub Pages

1. Pastikan `index.html` berada di root repositori.
2. Push seluruh berkas proyek ke repositori GitHub.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch utama (biasanya `main`) dan folder `/ (root)`, lalu klik **Save**.
6. Setelah proses deploy selesai, buka URL yang ditampilkan di halaman GitHub Pages.

## Catatan
